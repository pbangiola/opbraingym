Build plates: which one?

A reference for the original Bambu Textured PEI, Engineering Plate and Cool Plate used with the P1S. These names refer to specific surfaces and generations; the original Cool Plate is different from Cool Plate SuperTack.

Quick decision

  • Everyday PLA: Textured PEI is a starting point; the original Cool Plate is another workflow when its low-temperature profile suits the job.
  • PETG or TPU: check Textured PEI compatibility and the material’s release-layer directions first.
  • ABS, ASA, PA or PC: start with the exact filament / plate compatibility guidance, not a universal “engineering materials” rule.

Select the actual plate in Bambu Studio. Clean it using the plate maker’s instructions; avoid substituting cleaning or adhesion advice from another surface.
